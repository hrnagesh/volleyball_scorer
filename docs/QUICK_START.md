# Quick Start Guide - VB Match Tracker Pro

## 🚀 Get Started in 30 Seconds

### Step 1: Open the App
```
Open: volleyball_score_enhanced.html
In: Any modern web browser
```

### Step 2: Customize Teams
```
1. Click team names in header
2. Enter custom names (e.g., "Sharks" and "Dragons")
3. Save
```

### Step 3: Add Players (Optional)
```
1. Click 👥 button
2. Select Team A
3. Enter player name and number
4. Click "Add"
5. Repeat for Team B
```

### Step 4: Start Scoring
```
1. Click the large score number OR
2. Click +1 button to add point
3. Repeat for the other team
4. Match auto-detects set winners
```

### Step 5: View Statistics
```
1. Click 📊 button
2. See real-time stats
3. View court positions
4. Check win percentages
```

## 🎯 Common Tasks

### Task: Add a Point
```
Method 1: Click the big score number
Method 2: Click +1 button below score

Result: Point added, sound plays, stats update
```

### Task: Undo Last Action
```
Method 1: Click ↶ button
Method 2: Open history and click action in timeline

Result: Score reverts to previous state
```

### Task: Call a Timeout
```
1. Click TO button during match
2. Timeout deducted from team
3. Dots change to gray
4. Resets with new set
```

### Task: End a Set
```
Method 1: Auto-detection (when score reaches 25 with 2-lead)
Method 2: Manually click +Set button
Result: Points reset, toast notification
```

### Task: Start New Match
```
1. Click Reset button in header
2. Confirm reset
3. All scores clear
4. New match begins
```

### Task: Save & Export
```
1. Click 📜 (History Panel)
2. Click "📥 Export PDF" or "📊 Export CSV"
3. File downloads automatically
4. Open file on your computer
```

### Task: Change Scoring Rules
```
1. Click ⚙️ (Settings)
2. Adjust:
   - Regular Set Points: 25 (or custom)
   - Final Set Points: 15 (or custom)
   - Minimum Lead: 2 (or custom)
3. Click "Save Settings"
```

### Task: Track by Position
```
1. Click 📊 (Stats Panel)
2. Click position in court diagram
3. Selected position highlights
4. Next point scores from that position
5. Auto-tracks in position statistics
```

## 📊 Reading Statistics

### Win Percentage
```
Shows: Percentage of sets each team has won
Formula: (Sets Won / Total Sets) × 100
Example: Team won 2 of 3 sets = 66%
```

### Position Stats
```
Shows: Points scored from each position
Front Row: LF, CF, RF (left, center, right forward)
Back Row: LB, CB, RB (left, center, right back)
Totals break down Front vs Back row
```

### Match Duration
```
Shows: How long match has been playing
Format: MM:SS (minutes:seconds)
Updates: Every second, auto-displayed in header
```

## 🎓 Scorekeeping Rules (Standard Volleyball)

- **Regular Set**: First to 25 points with 2-point lead
- **Final Set**: First to 15 points with 2-point lead
- **Timeouts**: 2 per team per set
- **Set Win**: 3 sets total wins the match
- **Rally Scoring**: Every serve is a point (modern rules)

*Note: All configurable in Settings → Scoring Rules*

## 📈 Typical Match Flow

```
1. Set starts (0-0 points)
2. Teams score points
3. First team reaches setting (usually 25 pts + 2 lead)
4. Set winner declared automatically
5. Toast notification appears
6. Points reset to 0-0
7. New set begins
8. Repeat until team wins 3 sets
9. Match ends automatically
10. Save/export match history
```
